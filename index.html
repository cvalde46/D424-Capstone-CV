Vacation Scheduler Mobile Application

The Vacation Scheduler mobile application allows users to create, manage, and track vacations and associated excursions in one centralized location. The application supports vacation and excursion management, search functionality, alerts for important dates, and report generation.

Installation Instructions

Instructions for Andriod 1. Download the APK file using the link above.

4. Once installed, launch the application from your device. Instructions for Desktop 1. Download the APK file using the link above.
2. Download Andriod Studios or IDE capable of running APK files 3. Open the application in the designated IDE 4. Run the application in release mode

System Requirements

Android 8.0 (API level 26) or higher is required to run this application. No internet connection is required after installation.
